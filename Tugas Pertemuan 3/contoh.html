Bootstrap Popover

Kompilasi contoh nyata penggunaan popover dalam antarmuka aplikasi modern — dari form, toko online, hingga dashboard.

Contoh 1

Arah Kemunculan Popover

Tombol aksi di halaman pemesanan tiket — setiap tombol menampilkan keterangan singkat sesuai posisinya.

Arahkan / klik tombol di bawah:

<button data-bs-toggle="popover" data-bs-placement="top" data-bs-title="Pesan Tiket" data-bs-content="Klik untuk memilih kursi..."> Pesan </button>
Contoh 2

Mode Trigger: Click & Hover

Di halaman produk e-commerce — hover untuk pratinjau cepat, klik untuk informasi detail.

👟
Air Max 270
Rp 1.850.000
🎧
Sony XM5
Rp 4.299.000

Klik kotak pencarian:

/* Hover */ data-bs-trigger="hover" /* Click */ data-bs-trigger="click" /* Focus */ data-bs-trigger="focus"
Contoh 3

Panduan Isian Form Registrasi

Popover membantu pengguna memahami format & syarat input tanpa memenuhi layar dengan teks.

<i data-bs-toggle="popover" data-bs-trigger="hover focus" data-bs-title="Format Username" data-bs-content="4–20 karakter..."> </i>
Contoh 4

Kontrol Popover via JavaScript

Dashboard admin — toggle notifikasi status server secara manual lewat kode.

Server: Online

Popover telah dihapus dari elemen. Refresh halaman untuk mengembalikan.

const el = document.getElementById('serverPopoverTarget'); const serverPop = new bootstrap.Popover(el, { title: 'Status Server', content: 'Uptime 99.9% · Ping 12ms · Jakarta DC', placement: 'top', trigger: 'manual' }); serverPop.show(); // tampilkan serverPop.hide(); // sembunyikan serverPop.toggle(); // toggle serverPop.dispose(); // hapus

Konten HTML di Dalam Popover

Toolbar teks editor — popover menampilkan shortcut keyboard beserta deskripsi format.

Toolbar Rich Text Editor:

<button data-bs-toggle="popover" data-bs-html="true" data-bs-title="<i class='bi bi-type-bold'></i> Bold" data-bs-content="Cetak tebal.<br><kbd>Ctrl+B</kbd>"> B </button>

Referensi

Opsi Bootstrap Popover

Tabel ringkas opsi paling umum digunakan dalam proyek nyata.

Opsi Tipe Default Keterangan
placement string top Posisi: top / bottom / left / right / auto
trigger string click click · hover · focus · manual
html boolean false Izinkan tag HTML dalam konten
delay number 0 Jeda (ms) sebelum tampil/hilang
container string false Selector elemen induk popover
animation boolean true Animasi fade saat tampil/hilang
